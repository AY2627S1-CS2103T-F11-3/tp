**SquadLink is a desktop application to help youth football coaches manage player profiles, squads and availability.** While it has a GUI, most of the user interactions happen using a CLI (Command Line Interface).

* To use SquadLink, start with the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* To develop SquadLink, see the [**Developer Guide**](DeveloperGuide.html).
* Download the application from [SquadLink Releases](https://github.com/AY2627S1-CS2103T-F11-3/tp/releases).
